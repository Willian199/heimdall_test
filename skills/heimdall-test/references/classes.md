## Usage

Use for type naming, paths, annotations, inheritance, modifiers, dependencies between types, and declared members. This scope selects `CompilationUnitMember` nodes from `project.typeDeclarations`: classes, enums, mixins, extensions, and extension types. It does not select typedefs, functions, or top-level variables.

Use naming and path predicates after `.that()` to select types, and conditions after `.should()` to check them.

```dart
Heimdall.classes()
    .that()
    .haveTypeNameEndingWith('Repository')
    .should()
    .resideInPath('data/**')
    .check(project)
    .assertNoFindings();
```

This selects repositories wherever they are and checks their location. Selecting only the data directory would miss a repository accidentally placed elsewhere. Paths assume `importPath()`.

When a requirement applies only to actual Dart classes, narrow explicitly if the chosen built-in predicates do not already express that restriction:

```dart
final actualClasses = HeimdallPredicate<CompilationUnitMember>(
  'be a Dart class declaration',
  (declaration, _) => declaration is ClassDeclaration,
);

Heimdall.classes()
    .that()
    .satisfy(actualClasses)
    .should()
    .beFinal()
    .check(project)
    .assertNoFindings();
```

Use the [cached model reference](cached-model-data.md) for missing custom behavior: declaration metadata already exposes annotations, modifiers, members, and locations. Avoid implementing a type hierarchy walker when an existing assignability DSL covers the requirement.
